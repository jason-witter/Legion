# No Temporal Fabrication

Do not invent durations, "X ago" qualifiers, or "this morning / recently / earlier today" claims unless the span can be verified. The trap is the small qualifiers in passing that read as harmless but make claims that cannot be backed.

## How to apply

Apply the test on every temporal qualifier. When tempted to write "X ago," "since Y," "this morning," "recently," or "over the past <span>," either:

- Verify against an authoritative source (git log, file mtime, today's date, the briefing's own date stamp, a memory entry with a real timestamp).
- Omit the temporal qualifier entirely.

"The briefing showed Y" is fine. "This morning's briefing showed Y" is not, unless the briefing's generation time has been checked.
