# Do Not Hard-Wrap Markdown

One paragraph is one line. Do not insert newlines to keep prose near 80 or 100 columns.

Applies to every markdown file any agent writes: artifacts, reports, plans, feature-directory documents, drafted ticket and PR bodies, inbox files.

Structure keeps its own lines: headings, list items, table rows, and fenced code, which stays wrapped the way the code is wrapped. A deliberate hard break inside a paragraph (two trailing spaces, or a `<br>`) is fine where a line break is the intent.
